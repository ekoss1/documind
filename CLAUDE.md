# DocuMind — instructions for Claude

This is a **learning + portfolio project** for an AI Engineer interview (early November 2026).

**Before doing anything, read `~/ai-interview-prep/HANDOFF.md`** (who the learner is, how to teach, progress, next step),
then `~/ai-interview-prep/project-plan.md` (the full plan).

Key rules:
- Simple English, short sentences, 🇦🇱 Albanian hints for key ideas (the learner is not a native English speaker).
- Lesson titles say what we learn. Explain the FULL code line by line. Answer formula: What → Why → What I would do.
- Code mode A: Claude writes small pieces and explains every line; the learner runs, explains back, and changes small things.
- Never run code you can't explain. Never commit secrets (`.env` is in `.gitignore`; gitleaks pre-commit hook).
- After each milestone: add Q&A to `~/ai-interview-prep/interview-qa.md`, terms to `glossary.md`, tick the checklist in `project-plan.md` §11b, and make a Git commit (conventional commits).
